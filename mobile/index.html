Búsqueda real de productos (por API)

Con clave Keepa, Mercado trae productos reales de Amazon (precio, ventas estimadas, reseñas) vía API. Sin clave, ves un ejemplo claramente marcado. Importante: ningún modelo de IA (Claude/ChatGPT/Gemini) da estos datos — los números reales vienen de la API de datos; la IA solo los interpreta.

¿Keepa web (19 €) o la API (49 €)? — cuál conviene

Son dos productos distintos de Keepa. No necesitás la API de 49 € para investigar productos.

  • Keepa web (~19 €/mes): historial de precio y ranking (BSR) para mirar a mano antes de comprar. Te dice si la demanda es estable o un pico que ya pasó. Es lo que te conviene para arrancar.
  • Keepa API (49 €/mes): solo sirve para que la app traiga esos datos automáticamente (se pega en el campo de arriba). Recién vale la pena más adelante, con productos ya andando y para automatizar.

Alternativa: Helium 10 tiene plan gratis y cubre keywords, productos y competencia; Jungle Scout hace lo mismo pero sin free.

Tu app ya trae el motor propio gratis (keywords + números + asesor de éxito), así que la investigación la tenés cubierta. Estas herramientas son para validar a mano el candidato. Nada reemplaza la orden de prueba de 1.000–2.000 US$.
